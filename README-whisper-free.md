# التسميع المجاني بـ Whisper

ارفع هذين الملفين إلى **نفس المجلد** في مستودع GitHub Pages:

- `grammar-whisper-free.html` (يمكنك تسميته `index.html`)
- `whisper-worker.js`

لا تضع مفتاح API في الموقع؛ هذه النسخة لا تحتاج أي مفتاح أو خادم.

عند أول ضغط على «ابدأ التسميع»، ينزّل المتصفح نموذج Whisper الإنجليزي ويحفظه في كاش المتصفح. لهذا قد يستغرق التحميل الأول وقتًا وبيانات إنترنت، ثم يصبح الاستخدام اللاحق أسرع. يعمل التعرف داخل جهاز المستخدم، ولا يرسل التسجيلات إلى خادم الموقع.

استخدم GitHub Pages عبر رابط `https://`، لأن المتصفح لا يسمح بالميكروفون عادةً على ملف محلي `file://`.
